# Mrityunjay Gupta — Personal Portfolio

A dependency-free, ten-page portfolio adapted from the supplied Ariana portfolio structure, with original content grounded in the PROOF documents and submitted Penn application.

## Open immediately

Open `public/index.html` in a browser. The complete site, including videos, images, and PDFs, is available without installation.

## Run

```sh
npm run build
npm run check
npm run dev
```

Open http://127.0.0.1:4173. Alternatively, open dist/index.html directly; all links use relative paths. Deploy the contents of dist to a static host.

## Edit

- `src/site.mjs`: page shell, homepage, recognition, navigation, and source links.
- `src/narratives.mjs`: project, research, work, music, and community narratives.
- `src/visuals.mjs`: AmbuGo interface concepts and reusable visual components.
- `src/penn.css`: cream-white, Penn navy (#011F5B), and crimson (#990000) design overrides.
- `src/style.css`, `editorial.css`, `responsive.css`, `evidence.css`: retained template design components.
- `public`: user media, web-optimized videos, research PDFs, supporting records, fonts, and award marks.
